# Cell Infection Simulation

A university project written in **C++** using **wxWidgets** that visualizes the spread of an infection across a grid of cells.

Cells can transition between healthy, infected and immune states based on configurable simulation parameters.

## Features

* configurable grid size
* adjustable infection probability
* configurable infection and immunity duration
* adjustable simulation speed
* infection started from the center or selected manually
* customizable cell colors
* real-time statistics for healthy, infected and immune cells

## Technologies

C++ · wxWidgets · Object-Oriented Programming
